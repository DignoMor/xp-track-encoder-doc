# Embedding

Embedding export produces one embedding per genomic element from a compatible
processed dataset and encoder artifact, preserving processed-dataset row order
so embeddings join back to the correct genomic elements.

This page currently maps the final step of the journey. Full guidance — the
embedding command, compatible encoder artifacts, content identities,
incompatibility refusals, and the exported array, manifest, and copied region
information — arrives with the embedding guide. It builds on a prepared
dataset (see [Preparation](preparation.md)) and a trained run (see
[Training](training.md)).
